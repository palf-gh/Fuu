Fuu (封) アルファ版の 3 回目です。The third alpha of Fuu (封).

> **アルファ版 / Alpha.** 基本の機能はそろっていますが、不具合や仕様の変更がありえます。
> The basics are in place, but expect bugs and changes.

## 変更点 / Changes since v0.1.0-alpha.2

- **会話の展開。** 一覧の矢印から、関連する受信メールと送信済みの返信をまとめて確認できます。

  **Conversation expansion.** Expand a message in the list to see related messages and sent replies.

- **自動更新。** 起動して少しすると GitHub で新しいバージョンを確かめ、あればタイトルバーに更新のボタンが出ます。押すとダウンロードし、署名を確かめてから入れ替えます。設定 →「一般」で確認を止めたり、すぐに確かめたりできます。
  **Self-update.** Shortly after start-up Fuu checks GitHub for a new version and shows an update button in the title bar. It downloads the update, verifies its signature and swaps it in. Turn the check off or check now under Settings → General.
- **11 の言語。** 英語、日本語、中国語（簡体字・繁体字）、韓国語、ポルトガル語（ブラジル）、スペイン語（スペイン・ラテンアメリカ）、ドイツ語、フランス語、インドネシア語。OS の言語に合わせ、設定 →「言語」で切り替えられます。日本語以外は AI の翻訳です。直してほしいところは Issue や Pull Request で教えてください。
  **Eleven languages.** English, Japanese, Chinese (Simplified, Traditional), Korean, Portuguese (Brazil), Spanish (Spain, Latin America), German, French and Indonesian. Fuu follows the system language; switch under Settings → Language. Translations other than Japanese are AI-made: corrections are welcome in an issue or pull request.
- **Intel Mac に対応**（`Fuu_0.1.0-alpha.3_x86_64.dmg`）。パッケージはすべて GitHub Actions でビルドし、`SHA256SUMS.txt` を添えています。
  **Intel Macs** are supported (`Fuu_0.1.0-alpha.3_x86_64.dmg`). All packages are now built by GitHub Actions, with `SHA256SUMS.txt`.
- 保存に失敗しても、保存済みのパスワードやログインが消えないようにしました。
  A failed write no longer loses a saved password or sign-in.
- アカウントの編集で、保存済みのパスワードを伏せ字で表示し、目のボタンで表示を切り替えられるようにしました。
  Editing an account shows the saved password, masked, with an eye button to reveal it.
- 署名が CRLF の改行のとき、返信の見出し（差出人など）の太字が崩れる問題を直しました。
  Reply header labels stay bold when the signature uses CRLF line breaks.
- README を言語ごとのファイルに分けました（英語が `README.md`）。
  The README is split into one file per language (`README.md` is English).

## 既知の制限 / Known limitations

- 会話の検索対象は現在のフォルダーと送信済みフォルダーです。メールは元の一覧にも個別に表示されます。

  Conversation searches cover the current folder and Sent; messages also remain individually visible in the list.

- **macOS**: 署名・公証がまだです。初回はシステム設定の「プライバシーとセキュリティ」で「このまま開く」を選んでください。
  Not signed or notarised yet: the first time, allow it under System Settings → Privacy & Security → Open Anyway.
- **Windows**: インストーラーに署名がないため、SmartScreen の警告が出ることがあります。
  The installer is unsigned, so SmartScreen may warn.
- **Linux**: パスワードの保存には Secret Service（GNOME キーリング、KWallet など）が必要です。`.deb` で入れた場合、更新はパッケージで行います（Fuu は Releases のページを開きます）。
  Saving passwords needs a Secret Service (GNOME Keyring, KWallet, …). A `.deb` install is updated as a package (Fuu opens the Releases page).
- OAuth のクライアント ID は同梱していません（README を参照）。/ No OAuth client IDs are bundled (see the README).
