Fuu (封) アルファ版の 4 回目です。The fourth alpha of Fuu (封).

> **アルファ版 / Alpha.** 不具合や仕様の変更がありえます。
> Expect bugs and changes.

## 変更点 / Changes since v0.1.0-alpha.3

- Windows と macOS で、簡体中国語の一部が四角く表示される問題を修正しました。日本語・繁体中国語・韓国語も含め、使用可能なシステムフォントを代替フォントとして使います。

  Fixed missing Simplified Chinese characters on Windows and macOS. Available system fonts are used as fallbacks for mixed Japanese, Traditional Chinese and Korean text.

## ダウンロード / Downloads

- Windows x64: `fuu_0.1.0-alpha.4_x64-setup.exe`
- macOS Apple silicon: `Fuu_0.1.0-alpha.4_aarch64.dmg`
- macOS Intel: `Fuu_0.1.0-alpha.4_x86_64.dmg`
- Linux x86_64: `fuu_0.1.0-alpha.4_amd64.deb` / `fuu_0.1.0-alpha.4_x86_64.AppImage`

alpha.3 からはアプリ内の更新ボタンを使用できます。`.deb` 版はパッケージを手動で更新してください。

From alpha.3, use the update button in the app. Update `.deb` installations manually using the package.

## 既知の制限 / Known limitations

- Windows のインストーラーは未署名のため、SmartScreen の警告が出ることがあります。
- macOS のアプリは未署名・未公証のため、初回起動時にシステム設定で許可が必要な場合があります。
- 必要な文字を含むフォントがシステムにない場合は、対応するフォントのインストールが必要です。
- OAuth のクライアント ID は同梱していません。

- The Windows installer is unsigned and may trigger SmartScreen.
- The macOS app is unsigned and not notarised; you may need to allow it in System Settings on first launch.
- If the system has no font containing the required characters, install a suitable font.
- OAuth client IDs are not bundled.
