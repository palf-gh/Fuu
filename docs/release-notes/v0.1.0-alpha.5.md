Fuu (封) アルファ版の 5 回目です。The fifth alpha of Fuu (封).

## 変更点 / Changes since v0.1.0-alpha.4

- 回線が遅いとアプリ内更新が 30 秒でタイムアウトする問題を修正しました。更新ファイルのダウンロードは最大 30 分待ち、インストール前に署名を検証します。

  Fixed in-app updates timing out after 30 seconds on slower connections. Update downloads can now run for up to 30 minutes and are verified before installation.

## 更新方法 / Updating

alpha.3 と alpha.4 には短いタイムアウトがあるため、更新に失敗する場合は下記のインストーラーを手動でダウンロードしてください。alpha.5 以降は、より遅い回線でもアプリ内更新を利用できます。

Alpha.3 and alpha.4 have the shorter timeout. If the update fails, download and install the appropriate package below. Alpha.5 allows more time for subsequent in-app updates.

- Windows x64: `fuu_0.1.0-alpha.5_x64-setup.exe`
- macOS Apple silicon: `Fuu_0.1.0-alpha.5_aarch64.dmg`
- macOS Intel: `Fuu_0.1.0-alpha.5_x86_64.dmg`
- Linux x86_64: `fuu_0.1.0-alpha.5_amd64.deb` / `fuu_0.1.0-alpha.5_x86_64.AppImage`

`.deb` 版はパッケージを手動で更新してください。Update `.deb` installations manually using the package.

Windows のインストーラーは未署名、macOS のアプリは未署名・未公証です。OAuth のクライアント ID は同梱していません。

The Windows installer is unsigned; the macOS app is unsigned and not notarised. OAuth client IDs are not bundled.
